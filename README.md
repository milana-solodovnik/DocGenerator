# 📄 Автоматический генератор документов о задолженностях

Программа для бухгалтеров, которая автоматически заполняет шаблоны документов данными из Excel таблицы с задолженностями.

## 🎯 Назначение

У вас есть:
- **Excel таблица** с данными о задолженностях между компаниями (суммы, договоры, УПД, платежные поручения, даты)
- **Шаблон документа** (текстовый файл) с готовым текстом, где числовые значения и названия указаны примерно

Программа:
1. Анализирует шаблон документа
2. Находит в нём числовые значения (суммы), даты, названия договоров
3. Заменяет их на реальные данные из Excel таблицы
4. Преобразует суммы в прописной формат (рубли + копейки словами)
5. Создаёт готовые документы для каждой записи в таблице

```

## 📋 Как использовать

### Шаг 1: Подготовка Excel таблицы

Ваша Excel таблица должна содержать столбцы с понятными названиями, например:

| Компания | Клиент | Общая_задолженность | Договор_1 | Сумма_Договор_1 | УПД_Договор_1 | ... |
|----------|--------|---------------------|-----------|-----------------|---------------|-----|
| ООО "Вектор" | АО "СтройМаш" | 1314055.58 | Договор-1 | 409184.40 | УПД № 221 от 22.06.2026 | ... |

**Рекомендуемые названия столбцов:**
- `Компания`, `Организация` - название вашей компании
- `Клиент`, `Контрагент` - название компании-клиента
- `Общая_задолженность`, `Сумма` - общая сумма долга
- `Договор_N`, `Сумма_Договор_N` - номер договора и сумма по нему
- `УПД_Договор_N` - номера УПД по договору
- `Платежки_Договор_N` - номера платежных поручений
- `Дата_составления` - дата документа

### Шаг 2: Подготовка шаблона документа

Создайте текстовый файл с шаблоном документа. Пример:

```
2. На дату подписания Соглашения у Стороны-2 перед Стороной-1 имеется
задолженность за поставленную продукцию в общей сумме 1 314 055,58 (Один миллион
триста четырнадцать тысяч пятьдесят пять рублей 58 копеек), в т.ч.:

По Договору-1: 409 184,40 руб. (Четыреста девять тысяч сто восемьдесят четыре рубля 40
копеек), что подтверждается УПД № 221 от 22.06.2026, платежными поручениями 53 от 09.06.2026 г.;
```

**Важно:** Программа автоматически распознаёт:
- Числовые значения (суммы) - заменит на данные из столбцов с суммами
- Суммы прописью в скобках - преобразует новые суммы в слова
- Даты в формате ДД.ММ.ГГГГ - заменит на даты из таблицы
- Названия компаний (Сторона-1, Сторона-2) - заменит на названия из таблицы
- Метки в квадратных скобках `[Компания]`, `[Клиент]` - заменит на соответствующие значения

### Шаг 3: Работа в программе

1. **Выбрать Excel файл** - загрузите вашу таблицу с задолженностями
2. **Выбрать шаблон документа** - загрузите текстовый шаблон
3. **Настроить сопоставление** (опционально) - посмотрите, какие поля найдены
4. **Сгенерировать документ** - программа создаст документы для всех записей
5. **Сохранить результат** - сохраните в TXT или DOCX формат

## 🔧 Особенности работы

### Автоматическое распознавание

Программа умеет:
- ✅ Находить все числа в шаблоне и заменять их на суммы из таблицы
- ✅ Преобразовывать суммы в прописной формат (1 314 055,58 → "Один миллион триста четырнадцать тысяч пятьдесят пять рублей 58 копеек")
- ✅ Заменять даты из таблицы на даты в шаблоне
- ✅ Заменять "Сторона-1" на название компании, "Сторона-2" на название клиента
- ✅ Обрабатывать несколько договоров в одном документе

### Форматирование чисел

- Числа форматируются с пробелами как разделители тысяч: `1 314 055,58`
- Копейки указываются через запятую
- Суммы прописью склоняются по правилам русского языка

## 💡 Примеры использования

### Пример 1: Стандартное соглашение о взаиморасчетах

**Excel таблица:**
| Компания | Клиент | Общая_задолженность | Договор_1 | Сумма_Договор_1 | ... |
|----------|--------|---------------------|-----------|-----------------|-----|
| ООО "Вектор" | АО "СтройМаш" | 1314055.58 | Договор-1 | 409184.40 | ... |

**Шаблон:**

... у Стороны-2 перед Стороной-1 имеется задолженность в общей сумме 1 314 055,58

```

**Результат:**
```
... у АО "СтройМаш" перед ООО "Вектор" имеется задолженность в общей сумме 
1 314 055,58 (Один миллион триста четырнадцать тысяч пятьдесят пять рублей 58 копеек)...
```

### Пример 2: Несколько договоров в одном документе

Программа автоматически обработает все договоры из таблицы:
- Договор-1: сумма, УПД, платежки
- Договор-2: сумма, УПД, платежки
- Договор-3: сумма, УПД, платежки

## ⚠️ Важные замечания

1. **Кодировка файлов**: Используйте UTF-8 для текстовых файлов
2. **Формат дат**: Даты в Excel должны быть в формате даты, а не текста
3. **Числовые значения**: Суммы должны быть числами, а не текстом
4. **Шаблоны**: Чем точнее шаблон соответствует структуре данных, тем лучше результат
