# Генератор документов по задолженностям

Программа для автоматического заполнения документов данными о задолженностях из Excel таблицы.

## 📋 Описание

Эта программа помогает бухгалтерам автоматически генерировать документы (акты сверки, письма и т.д.) на основе данных из Excel таблицы с задолженностями между компанией и клиентами.

## 🔧 Требования

- Python 3.7+
- Библиотеки:
  - `tkinter` (входит в стандартную поставку Python)
  - `pandas`
  - `openpyxl`
  - `python-docx` (опционально, для работы с .docx файлами)

## 📦 Установка

```bash
pip install pandas openpyxl python-docx
```

## 🚀 Запуск программы

```bash
python debt_document_generator.py
```

## 📖 Инструкция по использованию

### Шаг 1: Подготовка Excel файла

Создайте Excel таблицу со следующими столбцами (названия могут быть любыми, программа автоматически их распознает):

| Компания | Клиент | Номер договора | Дата | Сумма задолженности | Валюта | Тип задолженности | Примечание |
|----------|--------|----------------|------|---------------------|--------|-------------------|------------|
| ООО Ромашка | ПАО Сбербанк | ДГ-123/2024 | 01.01.2024 | 150000 | RUB | Дебиторская | ... |

### Шаг 2: Создание шаблона документа

Создайте текстовый файл (.txt или .docx) с шаблоном документа. Используйте специальные метки для подстановки данных:

**Доступные метки:**
- `{{company}}` — название компании
- `{{client}}` — название клиента
- `{{contract_number}}` — номер договора
- `{{date}}` — дата договора
- `{{debt_amount}}` — сумма задолженности
- `{{total_debt}}` — общая сумма всех задолженностей (автоматический расчет)
- `{{current_date}}` — текущая дата (автоматически)
- `{{currency}}` — валюта
- `{{note}}` — примечание
- `{{debt_type}}` — тип задолженности

**Пример шаблона:**

```
АКТ СВЕРКИ ВЗАИМНЫХ РАСЧЁТОВ
№ {{contract_number}} от {{date}}

{{company}}, именуемое в дальнейшем «Компания», 
и {{client}}, именуемое в дальнейшем «Клиент»,

составили настоящий акт о нижеследующем:

Задолженность составляет: {{debt_amount}} {{currency}}.

Дата формирования: {{current_date}}
```

### Шаг 3: Работа с программой

1. **Загрузите Excel файл** — нажмите кнопку "📊 Выбрать Excel файл"
2. **Загрузите шаблон** — нажмите кнопку "📄 Выбрать шаблон документа"
3. **Сгенерируйте документ** — нажмите кнопку "✨ Сгенерировать документ"
4. **Сохраните результат** — программа предложит сохранить сгенерированный файл

## 💡 Особенности

- **Автоматическое сопоставление** — программа автоматически находит соответствия между метками в шаблоне и столбцами в Excel
- **Поддержка нескольких записей** — если в Excel несколько строк, программа создаст отдельный документ для каждой
- **Предпросмотр** — вы можете увидеть предпросмотр данных и результата перед сохранением
- **Гибкость** — можно использовать любые названия столбцов в Excel, главное чтобы они совпадали с метками в шаблоне

## ⚠️ Важные замечания

- Программа работает с файлами `.xlsx`, `.xls` (Excel) и `.txt`, `.docx` (шаблоны)
- Для работы с `.docx` файлами рекомендуется установить `python-docx`
- Все данные обрабатываются локально, ничего не отправляется в интернет
- Программа создает отдельные документы для каждой записи в Excel таблице

## 🛠️ Расширение функциональности

Вы можете легко добавить свои метки, просто:
1. Добавив соответствующий столбец в Excel таблицу
2. Используя метку с таким же названием в шаблоне (в нижнем регистре, с подчеркиваниями вместо пробелов)

Например, столбец "Номер счета" → метка `{{account_number}}`
